# Security Policy

## Supported versions

Security fixes are released for the latest version of Dalue.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/uuur86/dalue/security/advisories/new)
or by email to [contact@codeplus.dev](mailto:contact@codeplus.dev).

Include the affected version, a description of the problem and, if possible,
a minimal reproduction. You will receive an answer as soon as possible, and the
fix will be credited to you unless you prefer otherwise.
